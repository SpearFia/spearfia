# 1. Record architecture decisions

- Status: accepted
- Date: 2026-10-18

## Context

Spear Fia spans several repositories and will be worked on by people and agents.
Decisions need to be findable and their reasoning kept.

## Decision

We record significant decisions as Architecture Decision Records in `docs/adr/`,
numbered `NNNN-title.md`, using this format: Status, Date, Context, Decision,
Consequences. An ADR is proposed in a pull request and becomes accepted when merged.
Superseded ADRs stay in place and link to the one that replaces them.

## Consequences

Anything that changes the stack, a public format or the license gets an ADR first.
